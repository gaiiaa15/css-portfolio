Solara App | React Native and TypeScript

Github link: github.com/gaiiaa15/SolarEnergyApp

  • Developed a full-stack mobile application that estimates household
    solar-energy generation, electricity savings, and export revenue from property,
    energy-consumption, and solar-system data
  • Built a TypeScript, Node.js, and Express backend with structured route, service, middleware,
    and database layers supporting users, properties, solar systems, forecasts, generation,
    tariffs, and financial calculations.
  • Integrated Open-Meteo and PVGIS APIs to combine weather forecasts with location-specific
    solar-irradiation data and produce personalised energy predictions.
  • Implemented JWT-based authentication, bcrypt password hashing, protected API routes,
    parameterised MySQL queries, and an expiring password-reset-token workflow; continuing
    to test, debug, and refine the application.

Library Management System | Java Application

Github link: github.com/gaiiaa15/Library-Management-System
