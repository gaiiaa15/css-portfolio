# My Portfolio
This is a multi-page simple responsive portfolio.
The portfolio presents information about me, my technical skills, some major projects that I have created and my education history.
This is part of roadmap.sh full stack journey, a small project to help me practice and improve my HTML and CSS skills.

## Features
1. Simple navigation bar that ulternates between the main page and the projects page.
2. Responsive layout for different screen sizes.
3. **Project page** displays in depth informarion about my projects and what I used to build them.
4. **Home page** displays all the information about me that the recruitr might be looking for.

## Technologies Used
1. **HTML** used to create the main headings and the different sections.
2. **CSS** controls all the layout, colour, spacing properties and responsive behaviour.

## Development Tools
1. **Visual Studio** to write the code.
2. **GitHub** to make an online copy of my code, accessible through a link.

## Responsive Design
1. When the screen is  below 600px the flex layout changes to a vertical layout to make it, easier to read.
2. When the screen is bigger than 600px the flex layout goes back to horizontal, to make better use of the space given by a larger screen. 
3. This change was made to make the website suitable for all kinds of devices like, mobiles, tablets and laptops. 

## How To Run The Project
To run the project clone it on vidula studio, download the **Live Server extension** then press the "Go Live" button on the bottom right of your screen.
The website will open on your default browser.

## What I Learned 
1. How to use FlexBox
2. How to create a Responsive Layout
3. How to use of padding and margin and their differences
4. Linking multiple pages through navigation bar
5. How to use of Classes and IDs in both HTML and CSS
